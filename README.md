# CV Builder

CV Builder هو تطبيق مجاني يساعدك على إنشاء سيرة ذاتية احترافية بسهولة وسرعة.

## ✨ المميزات
- تصميم بسيط وسهل الاستخدام
- دعم اللغة العربية
- إمكانية تحميل السيرة الذاتية بصيغة PDF
- واجهة تفاعلية وسريعة

## 🚀 كيفية الاستخدام
1. افتح التطبيق من الرابط أو شغّله على جهازك.
2. املأ بياناتك الشخصية والتعليمية والمهنية.
3. اضغط على زر "تحميل السيرة الذاتية" للحصول على ملف PDF.

## 🛠️ التقنيات المستخدمة
- HTML / CSS / JavaScript
- Node.js (للسيرفر)
- Express.js
- Replit (بيئة التطوير)
